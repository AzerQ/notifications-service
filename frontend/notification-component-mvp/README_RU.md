# MVP Компонент InApp Уведомлений

Чистый, простой и готовый к использованию React-компонент уведомлений с обновлениями в реальном времени через SignalR.

## 🎯 Особенности

- ✅ **Изоляция стилей:** Использование CSS Modules для предотвращения конфликтов с хост-приложением.
- ✅ **Public API:** Глобальный объект `window.NotificationWidget` для управления извне.
- ✅ **Интерактивные кнопки:** Поддержка кнопок действий с протоколом `appaction://`.
- ✅ **Бесконечная прокрутка:** Автоматическая подгрузка старых уведомлений при скролле.
- ✅ **Поиск и фильтрация:** Поиск по заголовкам и тексту на стороне клиента.
- ✅ **Статус подключения:** Визуальный индикатор состояния SignalR соединения.
- ✅ **Авто-аутентификация:** Поддержка Windows и Email аутентификации "из коробки".
- ✅ **Real-time:** Мгновенное получение уведомлений без перезагрузки.
- ✅ **TypeScript:** Полная типизация всех интерфейсов и API.

## 📖 Использование

### Базовый пример

Компонент настраивается через переменные окружения (`.env`) и не требует ручной настройки стора при использовании стандартной обертки.

```tsx
import { NotificationComponent } from '@notifications-service/inapp-component-mvp';

function App() {
  return (
    <NotificationComponent
      onNotificationClick={(notification) => {
        console.log('Клик по уведомлению:', notification);
      }}
      showPreferencesButton={true}
    />
  );
}
```

## 🔌 Публичный API (Интеграция)

При встраивании как модуля, виджет предоставляет глобальный API через `window.NotificationWidget`.

### Методы

- `refresh(): Promise<void>` - Принудительное обновление списка с сервера.
- `open(): void` - Программное открытие выпадающего списка.
- `close(): void` - Программное закрытие выпадающего списка.
- `setToken(token: string): void` - Динамическое обновление JWT токена.
- `registerActionHandler(name: string, handler: (args: Record<string, string>) => void): void` - Регистрация обработчика для URL `appaction://`.

### Настройка аутентификации

По умолчанию компонент использует Windows и Email аутентификацию. Вы можете ограничить методы через конфиг:

```tsx
const store = useNotificationStore({
  // ...
  enabledAuthMethods: ['windows'] // Только Windows аутентификация
});
```

Подробную информацию см. в [ИНТЕГРАЦИЯ_RU.md](./INTEGRATION_RU.md).
